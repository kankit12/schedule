# ECU Class Navigator

This folder is ready for GitHub Pages.

1. Upload everything in this folder to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Open the published HTTPS link. On iPhone, use **Share → Add to Home Screen**. On Mac, use Safari's **File → Add to Dock**.

Location-based walking estimates require location permission. Live browser notifications run while the installed web app is active; the downloaded calendar includes the Route 302 reminder so that alert can fire when the web app is closed.
